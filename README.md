# The Princess Experience — React + MUI

Luxury landing site for a Princess 388 hospitality / experience concept.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

## Notes
- Built with React, Vite and Material UI.
- Responsive desktop/mobile navigation.
- Luxury editorial visual direction with champagne-gold, deep navy and ivory palette.
- Sections for experiences, yacht, occasions and the 2026/27 destination strategy.
- Enquiry modal is front-end only and ready to connect to a booking/CRM endpoint.
- Replace the two Unsplash background URLs in `src/styles.css` with supplied Princess 388 photography for the final production version.
- Pricing and destination messaging follows the supplied 2026/27 business plan and should be validated before launch.
